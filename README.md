# State PSC Exam Guide

A plain-language guide to State Public Service Commission exams in India, published by [Govtpvt](https://govtpvt.com/).

Live site: https://govtpvt-state-psc-guide.onrender.com/

## What is in this repository

| File | Covers |
|---|---|
| `index.html` | What a state PSC recruits for and the three-stage exam |
| `state-rules.html` | Domicile, age, attempts and language rules that differ between states |
| `state-paper.html` | Preparing the state-specific paper from official sources |

## Why it exists

Candidates often prepare for a neighbouring state's exam and find out late that reservation, age relaxation or language rules treat them differently from residents. These pages collect the points to check before applying.

## Keeping up to date

Rules change between cycles. Always confirm in the official notification. Current state and central notifications are listed under [latest government jobs](https://govtpvt.com/govt-job/latest-jobs), with results on the [Sarkari results](https://govtpvt.com/govt-job/latest-results) page.

## Corrections

If something here is out of date, open an issue with a link to the official notice.
